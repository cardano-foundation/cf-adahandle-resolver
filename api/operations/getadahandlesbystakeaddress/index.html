Handles held by a stake address

GET
/api/v1/ada-handles/by-stake-address/{stakeAddress}

Returns the names (without the leading $) of all handles held by addresses that belong to the given stake address: handles and NFT sub-handles held there, and virtual sub-handles whose datum points to such an address. Burned handles are not listed. Returns an empty list if there are none.

Parameters

Section titled “Parameters”

Path Parameters

Section titled “Path Parameters”

required

Responses

Section titled “Responses”

Section titled “200”

Media type*/*
Array<string>

Headers

Section titled “Headers”
X-Sync-Slot
integer format: int64

Slot of the last block indexed. Absent if nothing is indexed yet.

X-Sync-Status
string
Allowed values: synced syncing stale unknown

How current the data behind this answer is. synced: at the network tip and receiving blocks. syncing: catching up, so the answer can be out of date. stale: no block received from the node for a while, so the answer can be out of date. unknown: nothing indexed yet, or the network tip is not known.

X-Sync-Block
integer format: int64

Number of the last block indexed. Absent if nothing is indexed yet.

X-Sync-Tip-Slot
integer format: int64

Slot of the network tip, as last fetched from the node (refreshed every few minutes). Absent if not known.

X-Sync-Block-Time
string format: date-time

Time of the last block indexed (ISO 8601, UTC). Compare it with the current time to see how old the data is.
