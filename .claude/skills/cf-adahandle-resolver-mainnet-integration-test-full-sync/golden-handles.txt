# Golden ADA handles: well-known mainnet handles, at least one of every kind the resolver must
# handle. run-golden-handles.sh checks each one on every run against Kora Labs' Handles API
# (api.handle.me), the reference for who owns a handle: the resolver's payment address must equal
# Kora's resolved ADA address, and the reverse lookup must list the handle.
# One handle per line (no leading $); blank lines and # comments are ignored.
#
# Picked from Kora's API (handle_type, holder_type, policy as Kora reports them) and confirmed
# there, not from the resolver's own database. Names only, no addresses: handles change owner,
# so the expected address is read from Kora at run time.
# Run at the tip (a handle minted after a mid-sync cursor isn't indexed yet).
