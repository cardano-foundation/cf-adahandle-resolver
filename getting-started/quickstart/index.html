Quickstart

Just want to try the API?

The Cardano Foundation runs a public mainnet resolver: no setup, no API key.

See Public mainnet instance. Run your own, below, for preprod or preview, or to depend on no one else’s server.

  • Docker
  • Compose + PostgreSQL
  • From source

Give the JVM enough heap for mainnet

A full mainnet index holds about 266,000 handles and some 15 million history rows. With -Xmx2g the process runs out of memory during the initial sync. Use at least -Xmx4g, passed through JAVA_TOOL_OPTIONS when running in a container.

Upgrading to 1.0.0 needs a full resync

0.x ran on Yaci Store 0.1.x and 1.0.0 runs on Yaci Store 3.x, which ships a changed version of one of its database migrations (since 2.x). 1.0.0 also indexes handles that earlier versions didn’t. Stop the resolver, drop the database (docker compose down -v, or delete ./data/db* for H2), then start 1.0.0. A database created by 0.x fails on startup with Migration checksum mismatch for migration version 0.200.1.

Tip

The leading $ in a handle is optional. $alice and alice resolve to the same handle. In a shell, escape the $ or wrap the URL in single quotes so it isn’t expanded as a variable.
